# Чек-листы СМП

## 1. Дымовое тестирование

- [ ] SMK-01 Система собирается и запускается без ошибок, все контейнеры в рабочем состоянии
- [ ] SMK-02 Скрипт дымовой проверки репозитория проходит полностью
- [ ] SMK-03 Gateway, Switch, Authorization, Card-Management отвечают на проверку работоспособности
- [ ] SMK-04 Transaction Logger, Bin Lookup, Notification Service отвечают на проверку работоспособности
- [ ] SMK-05 Симуляторы терминалов и мерчантов отвечают на проверку работоспособности
- [ ] SMK-06 Web Dashboard и веб-интерфейс RabbitMQ открываются
- [ ] SMK-07 Генерация тестовых карт работает
- [ ] SMK-08 Создание и получение одной карты работает
- [ ] SMK-09 Одна корректная транзакция проходит через всю цепочку
- [ ] SMK-10 Симулятор терминалов отправляет поток транзакций

## 2. Критический путь

**Успешная покупка**

- [ ] CP-01 Корректная транзакция по активной карте одобряется
- [ ] CP-02 У одобренной транзакции есть идентификатор операции и код авторизации установленного формата
- [ ] CP-03 Баланс карты уменьшается на сумму транзакции
- [ ] CP-04 Транзакция попадает в журнал и на дашборд

**Отказы**

- [ ] CP-05 Неизвестная, неактивная, заблокированная карта или карта с истёкшим сроком — отказ
- [ ] CP-06 Сумма больше баланса или лимита — отказ
- [ ] CP-07 Отказ не меняет баланс и не расходует лимит
- [ ] CP-08 Отказы видны в журнале с причиной

**Сквозные сценарии**

- [ ] CP-09 Некорректный запрос отклоняется на входе
- [ ] CP-10 Смена статуса карты влияет на следующую транзакцию
- [ ] CP-11 Удалённая карта не участвует в авторизации
- [ ] CP-12 Откат возвращает средства на баланс
- [ ] CP-13 Недоступность Card-Management или Bin Lookup не ломает остальную систему и корректно обрабатывается
